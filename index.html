💡 为什么需要 SourceTrace？

当你的 AI Agent 需要引用法规、标准、监管动态时，它可能：

❌ 编造 URL 和日期 — 训练数据 cutoff 导致信息过时

❌ 混淆一手源和二手报道 — 把媒体报道当成官方原文

❌ 黑盒不可追溯 — 不知道答案从哪来，无法对账审计

SourceTrace 解决这些问题：

✅ 诚实降级 — 查不到就说查不到，绝不编造

✅ 审计 JSON — 每个结论都带一手源 URL + 时间线

✅ Agent 原生 — MCP/A2A 接口，调用方自动结算
